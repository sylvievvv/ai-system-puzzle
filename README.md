# AI system puzzle

An interactive page that explains how an AI application is put together, using six puzzle pieces:

1. **Frontend** – what the user sees
2. **Backend** – the director that coordinates everything
3. **AI model** – understands the question and decides what's needed (Claude, GPT, Gemini, Llama, …)
4. **Tools** – functions the model can ask the backend to run
5. **Database** – the application's memory
6. **Evaluation** – tests and monitors whether the system works

Click a piece to read what it does, an example, and how to explain it in a job interview. Below the puzzle you can follow one example question ("Why hasn't my order shipped yet?") step by step through the system.

## View it

Open `index.html` in any browser. No build step or internet connection needed.
